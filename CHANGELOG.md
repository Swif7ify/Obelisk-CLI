- Initial CLI framework with Cobra
- Secret scanner with regex and entropy detection
- `.gitignore` and `.env` integrity validation
- JavaScript/TypeScript framework adapter (React, Next.js)
- Dependency auditing for `package.json`
- Naming convention enforcement
- Circular dependency detection
- Google Gemini AI integration for health scoring

- Health Score grading (A–F)

- `obelisk protect` — Git pre-push hook integration
